历史 / 断点续播由本地数据库持久化
01 / 视频层
原生渲染 surface
libmpv 直接输出到窗口，Vue 的透明 WebView 只覆盖 UI。MKV / HEVC / AV1 / HDR 不依赖系统 WebView 解码能力。
02 / 控制条
悬浮 OSC
IINA 式底部渐显控制条，含缓冲进度、缩略图预览、字幕/音轨/倍速/逐帧。闲置自动隐藏，鼠标移入复现。
03 / 播放列表
侧栏与媒体库
可折叠侧栏，Pinia 持有播放状态，播放历史与断点续播落本地数据库。控件走 Ant Design Vue 暗色 token。
04 / 投屏面板
零安装设备发现
SSDP / mDNS 扫描 Android TV，手动 IP 作组播隔离兜底。连接后 PC 转为遥控器，显示电视端进度。
技术映射　Vue 3 + Ant Design Vue + Pinia → Tauri 2.12 IPC → Rust（libmpv + vuio-core + axum HTTP 206） → Android TV
